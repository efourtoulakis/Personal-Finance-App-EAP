# Personal Finance Management Application - Project ΕΑΠ

## Περιγραφή Project

Η εφαρμογή **Personal Finance Management Application** είναι μία desktop εφαρμογή διαχείρισης προσωπικών οικονομικών.

Αναπτύχθηκε στο πλαίσιο της ομαδικής προγραμματιστικής εργασίας του Ελληνικού Ανοικτού Πανεπιστημίου (ΕΑΠ) για το μάθημα ΠΛΗΠΡΟ, με στόχο την καταγραφή, παρακολούθηση και βασική ανάλυση εσόδων και εξόδων.

Η εφαρμογή εκτελείται μέσω Python και αποθηκεύει τα δεδομένα τοπικά σε SQLite βάση δεδομένων.

---

## Στόχος της Εφαρμογής

Στόχος της εφαρμογής είναι να παρέχει στον χρήστη ένα απλό και οργανωμένο περιβάλλον για τη διαχείριση των προσωπικών οικονομικών του.

Μέσω της εφαρμογής, ο χρήστης μπορεί να:

* δημιουργεί, τροποποιεί και διαγράφει κατηγορίες εσόδων και εξόδων,
* καταχωρεί, τροποποιεί και διαγράφει οικονομικές συναλλαγές,
* ορίζει επαναλαμβανόμενες μηνιαίες συναλλαγές,
* παρακολουθεί μηνιαία έσοδα, έξοδα και υπόλοιπο,
* προβάλλει γραφήματα οικονομικών δεδομένων,
* εξάγει δεδομένα συγκεκριμένου μήνα σε Excel και PDF.

---

## Βασικές Λειτουργίες

Η εφαρμογή υποστηρίζει:

* διαχείριση κατηγοριών εσόδων / εξόδων,
* διαχείριση συναλλαγών,
* φίλτρα συναλλαγών ανά εύρος ημερομηνιών (Από / Έως) και κατηγορία,
* recurring transactions για σταθερά μηνιαία έσοδα ή έξοδα,
* αυτόματη δημιουργία συναλλαγών από ενεργές recurring εγγραφές για επιλεγμένο διάστημα μηνών,
* γραφήματα με χρήση Matplotlib,
* export μηνιαίας αναφοράς σε Excel,
* export μηνιαίας αναφοράς σε PDF,
* τοπική αποθήκευση δεδομένων σε SQLite βάση.

## Αρχιτεκτονική Εφαρμογής

Η εφαρμογή ακολουθεί modular δομή, ώστε κάθε τμήμα να έχει ξεκάθαρη ευθύνη.

```text
GUI Layer
   ↓
Logic Layer
   ↓
Database Layer
   ↓
SQLite Database
```

Το GUI δεν εκτελεί SQL queries απευθείας. Οι λειτουργίες της βάσης περνούν από το αρχείο `Db/database.py`, ενώ η επιπλέον λογική βρίσκεται στον φάκελο `Logic`.

## Εκτέλεση Εφαρμογής

### Εκτέλεση μέσω Python / VS Code

1. Αποσυμπιέστε το αρχείο `.zip`.
2. Ανοίξτε τον φάκελο του project στο VS Code ή σε άλλο IDE.
3. Ανοίξτε terminal στον φάκελο του project.
4. Εγκαταστήστε τις απαραίτητες βιβλιοθήκες:

```bash
pip install -r requirements.txt
```

5. Εκτελέστε την εφαρμογή:

```bash
python main.py
```

Για την εκτέλεση απαιτείται εγκατεστημένη Python 3.

Το αρχείο `requirements.txt` περιλαμβάνει όλες τις απαραίτητες εξωτερικές βιβλιοθήκες της εφαρμογής.

Κατά την πρώτη εκτέλεση, η εφαρμογή δημιουργεί αυτόματα τη βάση δεδομένων `finance.db`, εφόσον δεν υπάρχει ήδη.

## Οδηγίες Χρήσης

Μετά την εκκίνηση της εφαρμογής, ο χρήστης μπορεί να χρησιμοποιήσει το αριστερό μενού για να μεταβεί στις βασικές ενότητες.

### Κατηγορίες

Ο χρήστης μπορεί να δημιουργήσει, να τροποποιήσει και να διαγράψει κατηγορίες εσόδων ή εξόδων, όπως μισθός, ενοίκιο, τρόφιμα, λογαριασμοί κτλ.

### Συναλλαγές

Ο χρήστης μπορεί να καταχωρεί έσοδα και έξοδα, επιλέγοντας κατηγορία, ποσό, ημερομηνία και περιγραφή.

Επίσης, μπορεί να φιλτράρει τις συναλλαγές με βάση εύρος ημερομηνιών (Από / Έως) και κατηγορία.

### Επαναλαμβανόμενες Συναλλαγές

Ο χρήστης μπορεί να ορίσει σταθερές μηνιαίες κινήσεις, όπως μισθό ή ενοίκιο.

Από τις ενεργές recurring εγγραφές μπορούν να δημιουργηθούν αυτόματα συναλλαγές για επιλεγμένο διάστημα μηνών.

### Γραφήματα / Export

Η εφαρμογή παρέχει γραφήματα για την παρακολούθηση των οικονομικών δεδομένων.

Τα διαθέσιμα γραφήματα είναι:

* έξοδα ανά κατηγορία,
* έσοδα ανά κατηγορία,
* μηνιαία σύνοψη εσόδων / εξόδων,
* υπόλοιπο ανά μήνα.

Τα γραφήματα υποστηρίζουν φίλτρα ημερομηνιών (Από / Έως) για πιο ευέλικτη ανάλυση των οικονομικών δεδομένων.

Η εφαρμογή υποστηρίζει επίσης εξαγωγή μηνιαίας αναφοράς σε:

* Excel αρχείο `.xlsx`,
* PDF αρχείο `.pdf`.
